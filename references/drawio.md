# drawio 轉檔步驟

把 drawio 架構圖重繪成報告用的 inline SVG 線路圖。格式與 參考報告 報告的「線路架構」章相同：

- 虛線分區框。
- 白底或淡色設備框，主機內有彩色介面框。
- 線依用途分色，線速寫在線上方。
- 圖下方附路徑表與「注意」卡。

範例：`examples/drawio-arch/`。`build_arch.py` 產生 `demo-arch.html`。

## 步驟

```
drawio ──1 render──▶ 原圖 PNG ──┐
   │                            ├──3 重排──▶ build_arch.py ──4 截圖比對──▶ 發布
   └──2 list──▶ 框與線清單 ──────┘
```

1. 把原圖每頁畫成 PNG：`python3 examples/drawio-arch/drawio_tool.py render <檔.drawio> <目錄>`。
2. 列出每個框與每條線：`python3 examples/drawio-arch/drawio_tool.py list <檔.drawio>`。
3. 複製 `build_arch.py`，只改「圖 1–3」的座標與路徑表。
4. 用無頭 Chrome 截圖，每條線和步驟 1 的 PNG 比對一次。再看一次手機寬（400px）。
5. 用 `scripts/publish.sh` 發到 space：先發 `-preview`，確認後再覆蓋正式檔名。

## 重排規則

- 依線路重排，不照 drawio 座標。由左到右放：來源 → 中間設備 → 終點主機。
- 每種用途一條橫列，例如對外流量、API、管理、站點互連。列標寫在列的左上方。
- 多條線共用一台設備時，只畫一個高框跨多列。線從框內穿過，框內那段用虛線。
- 主機畫成大框，內含介面框。介面框的顏色與進來的線相同。
- 設備歸屬用框色表示，沿用原圖顏色。要在圖上方加圖例。
- 單向線只在終點加箭頭。原圖兩端都有箭頭時，兩端都加。

## 判讀原圖的坑

- **只有座標的線**：`list` 顯示 `source`/`target` 是 None 時，這條線沒有接到框。要看 PNG 判斷接到哪裡。
- **子框座標是相對座標**：`parent` 不是 `1` 時，x、y 要加上 parent 的位置。
- **線穿過框**：drawio 的線常常只是從框上經過。看不出有沒有經過該設備時，照原圖畫，並寫進「注意」卡。
- **沒有名稱的框或設備**：不要自己取名。暫定名稱要寫明「原圖未標名」。只有圖示的設備，看 `prIcon`，例如 `firewall`、`l3_switch`。
- **線速**：依原圖圖例換算，例如實線 10G、虛線 100M。換算出來的線速寫進「注意」卡。
- **對外 IP、帳號**：報告與範例不放對外 IP、帳號、密碼。

## 版面檢查

- 標籤不可壓到框、線或分區標題。兩框間距至少 30（viewBox 單位）才放得下「10G」，「100M ×2」要 55 左右。
- 框內文字超出框寬時，加寬框。不要縮小字級；字級最小 10.5。
- 繞路的線不可穿過其他設備框。要繞到框的上方或下方。
- 圖例的 class 不要用 `.legend`。報告裡的圖表常已用 `.legend`（flex 版面），會把圖例文字拆開。範例用 `.arch-legend`。

## 反向：線路圖轉回 drawio

要在 drawio 裡用同樣的外觀時，把報告頁的線路圖轉回 drawio：

```
python3 examples/drawio-arch/svg2drawio.py <報告.html> <輸出.drawio>
```

- 每張 `<div class="fig arch">` 圖轉成一頁。頁名取該章 `.divider` 的標題。
- 框、文字、線都是 drawio 原生物件，可以直接編輯。
- 線的端點落在框邊上時，會接到該框。移動框時，線會跟著走。程式會印出「接到框的端點」數，沒接上的端點要看一下。
- 圖前有 `.arch-legend` 時，圖例畫在頁頂。
- 轉完用 `drawio_tool.py render` 畫成 PNG，和報告截圖比對一次。

注意：

- 之後只在 drawio 裡改圖，報告頁不會跟著變。要兩邊一致，就改 `build_arch.py`，再重跑兩支程式。
- drawio 的字比瀏覽器寬，框內標題最大用 12。標題換行時，把框拉寬。
